# Contributing

These are the defaults for every TheRadicalOnes repo. A repo can override them with its own `CONTRIBUTING.md`.

## Pull requests

- Title: `<PROJECT>-<ClickUp ID>: Short description`, e.g. `AMIA-123: Add membership renewal flow`.
- Fill in the PR template. It's shared across the org and lives in this repo.
- Add visual proof (screenshot, screencast or GIF) for anything a user can see.

## Branches and releases

Each project has its own branching model and release process. Look for them in that repo's `CONTRIBUTING.md` or `docs/` folder. If a project doesn't have one yet, ask the project lead before opening a PR into `main`.
